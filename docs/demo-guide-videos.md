# Banaoo — Demo Guide Videos (YouTube)

Suggested how-to videos for restaurant owners, managers, and staff.

**Audience:** New signups, existing users, support/onboarding.  
**Format:** 3–8 min each; screen recording + voiceover; show web dashboard unless noted (Android APK for printer/mobile topics).

**Priority:** P0 = must-have launch set · P1 = high value · P2 = nice-to-have / plan-specific

## 14. Production tips

- **Intro (5 sec):** “In this video you’ll learn…”
- **On-screen:** Highlight clicks; blur sensitive UPI/phone if demo account
- **End card:** banaoo.in · docs · connect@banaoo.in
- **Description template:** Link to docs article + signup + APK download
- **Languages:** English first; Hindi dubbing for top P0 videos
