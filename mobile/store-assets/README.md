# Google Play store graphics

Add finished files here before uploading in Play Console → **Main store listing**.

| File | Size | Notes |
|------|------|--------|
| `icon-512.png` | 512×512 PNG | High-res app icon (no transparency required) |
| `feature-graphic.png` | 1024×500 PNG/JPEG | Banner on store listing |
| `phone-screenshot-01.png` … `08.png` | 1080×1920 or 1440×2560 | Portrait phone screenshots, min 2 |
| `tablet-screenshot-01.png` … | 1200×1920+ | Optional 7" / 10" tablet |

**Tips**

- Show real POS screens: dashboard, new order, kitchen, printer setup.
- No misleading “#1” badges unless substantiated.
- Use the same brand colors as https://banaoo.in.

Copy for titles/descriptions is in `store-listing-en.txt`.
